## State / logic

- `state.share` default **true**; `toggleShare` -> `setState({share: !share})`; rendered via `sw(share)`.
- `state.linked` default false. `needLink = !linked`, `linked = !!linked`. Any of Apple/Google/이메일 -> `setState({linked:true})` -> link card replaced by green status row. (Real impl: anonymous-account upgrade via OAuth/email; show card only for guest users.)
- `state.themeSel` overrides theme if present (common.py convention).
- Streak 9 = yesterday's 8 + today; "최장 기록 경신" variant shown because new streak > previous best. Real impl needs non-record copy variant (not in mockup).
- Navigation: close -> Main, 다음 칸 보기 -> Curriculum, 홈으로 -> Main. Arrives from Tutor's `레슨 완료하고 잔디 채우기`.

## Motion CSS (verbatim)

```css
/* 레슨 완료: 색종이, 오늘 칸 채우기, 숫자 올라가기 */
.cf-fall{animation:cf-fall 2.6s ease-in 1 both}
.cf-fill{transform-origin:50% 100%;animation:cf-fill 0.7s cubic-bezier(.3,1.4,.5,1) 0.5s both}
.cf-up{animation:cf-up 0.6s ease-out 0.9s both}
@keyframes cf-fall{0%{transform:translateY(-40px) rotate(0deg);opacity:0}10%{opacity:1}100%{transform:translateY(260px) rotate(320deg);opacity:0}}
@keyframes cf-fill{0%{transform:scale(0)}100%{transform:scale(1)}}
@keyframes cf-up{0%{transform:translateY(12px);opacity:0}100%{transform:translateY(0);opacity:1}}
@media (prefers-reduced-motion: reduce){.cf-fall{animation:none;opacity:0}.cf-fill,.cf-up{animation:none}}
```
Sequence: confetti falls 0–~3.3s (staggered 0–0.72s), today cell pops in at 0.5s (overshoot bezier), streak number rises at 0.9s. Plus shared `ci-*` CSS (see Main.md); joy state uses `ci-hop` (1.4s infinite, -9px).
